# 电钢琴 edpiano

论坛全站悬浮 MIDI 钢琴播放器。MIDI 在浏览器里解析，音色用本地 SoundFont 采样实时合成（WebAudio），
服务器只负责列出 `midi/` 目录里的曲目 —— 不转码、不上传、不写数据库。

- 右下角一个小圆钮，点开是迷你播放器：曲名、进度（可拖）、上一首 / 播放 / 下一首、列表循环、音量
- 音色九档：**电钢琴**（Rhodes 风格，默认）、**三角钢琴**、**八音盒**、**木吉他**、**弦乐合奏**、
  **长笛**、**马林巴**、**小提琴+钢琴合奏**（自动分声部）、**架子鼓+钢琴**（MIDI 里的鼓轨用真鼓组照打），
  播放中也能切，切换时交叉淡入淡出；每种音色只在第一次选用时下载（约 0.8–3 MB，之后浏览器缓存）
- 换曲交叉淡入淡出，曲目之间不留空档；列表循环默认开
- **分类折叠**：曲目按分类分组显示（示例曲／动漫音乐／游戏音乐／流行金曲…），点组头收起／展开，
  每个分类的折叠状态记在会员浏览器里，换页、下次打开都保持；分类写在该曲 `.txt` 第三行，后台可改
- 换页后记住曲目与进度：浏览器允许时直接接上；被自动播放策略挡下时，圆钮变成「继续播放」胶囊，
  点一下从原位继续
- **多窗口同步**：同一个论坛开多个标签/窗口时，同一时间只有当前活跃的那个出声，其他窗口静音跟随，
  曲目、进度、音色、循环状态都同步；切窗口就从同一位置接着放
- 电脑版与手机版（触屏模板）都显示，后台可单独关掉手机版
- 不改模板、不改核心文件、不建表；停用插件即整站恢复原样

## 会员怎么用

1. 点右下角音符圆钮，面板展开并开始播放。
2. 面板里点曲目切换（交叉淡入淡出），点「电钢 / 大钢琴 / 八音盒 / 吉他 / 弦乐 / 长笛 / 马林巴 /
   小提琴+钢琴 / 架子鼓+钢琴」换音色（新音色第一次点选时要下载约 0.8–3 MB，之后走浏览器缓存）。
   「架子鼓+钢琴」会把 MIDI 自带的鼓轨用真鼓组打出来，没鼓轨的曲子听起来就是纯钢琴。
3. 换页、点帖子都不会停：新页面加载后自动从上次的位置接着放；如果浏览器拦了自动播放，
   圆钮会显示「继续播放」，点它即可。
4. 音量、音色、列表循环、面板收放状态、各分类的折叠状态都记在浏览器里（`localStorage`），下次打开还是这样。

## 分类

- 列表按分类分组，组头点一下收起／展开，再点回来；状态记在浏览器里（`edpiano.v1` 的 `closed` 字段）。
- 分类的来源：该曲 `.txt` 元数据的**第三行**（第一行曲名、第二行作者、第三行分类，20 字以内；
  作者空着时第二行要留空行——三行按位置取，不按非空行数），没有分类的曲子归进「未分类」组；
  后台「曲库管理」页每首多了一个「分类」输入框。
- 组的排列：按曲目第一次出现的顺序（即文件名自然排序），「未分类」固定排最后；
  组头带曲目数角标，当前播放曲子所在的组头会点亮，收起不影响播放与换页续播。

## 多窗口 / 多标签

同一个论坛开多个标签页或窗口时，**同一时间只有一个窗口出声**，不会两个窗口叠在一起放：

- 当前活跃（可见、有焦点）的窗口负责播放；其他窗口做静音跟随者，曲目、进度、音色、列表循环都同步，
  面板底部显示「另一窗口播放中 · 已同步」
- 切到另一个窗口，它在约 0.3 秒内从同一位置接手，原来那个窗口停下并转成跟随者
- 跟随者里点播放 / 暂停 / 上一首 / 下一首 / 拖进度 / 换音色，会先把这个窗口切成播放方再执行
- 所有窗口都最小化、或切去别的软件时，最后播放的窗口继续放（当作背景音乐）
- 正在播放的窗口关掉后，别的窗口不会自动接着响；回到任意窗口点一下播放即可，位置还在
- 实现：`BroadcastChannel` 通信 + 每秒心跳；不支持 `BroadcastChannel` 的老浏览器退回 `localStorage`
  的 `storage` 事件。只在最外层页面启用（站内 iframe 不挂播放器）；不同域名之间不互通

## 站长：曲库管理（后台网页）

后台 → 插件 → 电钢琴 → **曲库管理**（和「设置」并排的第二个标签）：

- **上传新曲**：一次可多选 `.mid` / `.midi`。校验：只收标准 MIDI（文件头 `MThd`）、单个 5MB 以内；
  文件名自动转成英文/数字/横杠，同名自动加 `-1` 后缀，不会覆盖旧文件。
- **改曲名 / 作者**：列表里每行直接填「曲名 / 作者」保存，写进同名 `.txt`（UTF-8）。
  两栏都留空再保存＝删掉 `.txt`，曲名回落为文件名。
- **调排序**：列表按文件名自然排序，改「文件名基名」就是调顺序（`01-`、`02-` 这样开头），
  改名会连带同名 `.txt` 一起改。
- **删除**：删 `.mid` 与同名 `.txt`，带确认弹窗。

改动对前台最多 60 秒生效（曲库接口带 60 秒浏览器缓存），播放器自动换列表，会员无需刷新两次。
页面顶部会做曲库目录可写检查，目录不可写时红字提醒（先给网站进程账号加
`source/plugin/edpiano/midi/` 的写入权限）。

## 加歌（老办法，一直可用）

把 `.mid` / `.midi` 放进：

```
source/plugin/edpiano/midi/
```

曲目列表由 `api.php` 扫目录生成，按文件名自然排序（`01-xxx.mid`、`02-xxx.mid` 这样排）。
想看中文曲名 / 作者，就在旁边放一个**同名** `.txt`（UTF-8）：

```
midi/01-rainy-street.mid
midi/01-rainy-street.txt     ← 第一行曲名，第二行作者（作者可留空）
```

删除文件即从列表消失。接口有 60 秒缓存，加完歌最多等一分钟；想立刻看到可加 `?t=随便` 刷新。

建议：

- 标准 MIDI（format 0 / 1）。打击乐轨（channel 10）平时忽略；选「架子鼓+钢琴」时用真鼓组照打，
  其余声部都用当前选的音色弹。
- 支持延音踏板（CC64），不支持弯音轮、音色切换、歌词等；太花的 MIDI 会用钢琴硬弹。
- 单曲几百到几千个音符都没问题；超大 MIDI（几万音符）第一次解析会慢一点。
- 文件名尽量用英文/数字，中文名写在 `.txt` 里，避免个别浏览器/服务器对 URL 编码处理不一致。

## 小提琴+钢琴合奏怎么分声部

音色选「小提琴+钢琴」时，按 MIDI 的结构处理：

- **多轨 MIDI（按原曲声部）**：取音域最高的那一轨当小提琴（旋律），其余声部给钢琴。
  例：《My Soul, Your Beats!》两轨版 = 右手旋律 275 个音给小提琴、左手伴奏 413 个音给钢琴。
- **单轨 MIDI（不拆旋律，原谱完整留给钢琴）**：钢琴照原谱弹，小提琴按下面的规则生成**和弦伴奏**。

### 单轨小提琴伴奏的规则

规则参照通用伴奏写作原则：**伴奏从属**（音量低于旋律）、**和声节奏跟乐句**（和弦变了才换和声）、
**共同音保持 + 级进声部连接**（不要每小节跳来跳去）、**抒情慢歌用长音/分解和弦而不是柱式和弦砸节奏**、
**钢琴停时和声要延续**（不能跟着一起断）。

1. **和声分析**：每小节按当时响的音做一次和声判断（12 个根音 × 大/小三和弦，按音的时值加权，
   低音在和弦里加分）。相邻和弦共同音 ≥ 2 且分数接近时不换，避免来回改。
2. **钢琴停顿**：没有音符的小节**沿用上一个和弦**，和声和伴奏都不断——这是「钢琴停、提琴也停」的修正。
3. **织体**：同一个和弦合并成一段，一段只起一次弓。低音声部拉长音铺底（2.8 秒换一次弓，
   避开采样 3.13 秒的长度）；高音声部每 3 秒走到邻近的和弦音，形成一条缓慢的内声部，
   不会一个双音从头拖到尾。
4. **声部连接**：新和弦的配音尽量贴近上一段（共同音保持、其余音级进），音区选在小提琴中高音区
   （低音 54–66、高音 62–76）、旋律下方，不跟钢琴抢旋律，但也不埋进钢琴的低音区。
5. **力度与音色**：低音 0.32、高音 0.28（钢琴通常 0.6–0.8）；小提琴单独走一个 180 Hz 高通
   加 2.6 kHz +4 dB 的 presence，跟钢琴叠在一起时更容易听出来，又不用把总音量推高。
6. **冲突检查**：每个伴奏音都跟同时响的钢琴音比对，避开半音/小九度/三全音；冲突先试升/降八度，
   仍冲突就不拉这个音。实测《哭砂》《蝶梦花雾雨》《雨后的街道》《東方萃夢想》的半音冲突都是 0。
7. **留白**：找不到干净和弦音的地方（例如很密的段落）宁可不拉，不硬凑。

例：《哭砂》生成约 204 个伴奏音、《蝶梦花雾雨》218 个、《東方萃夢想》66 个；音与音之间最长不超过
2.8–3 秒，钢琴停下来的段落伴奏仍然在走。

### 每首歌单独设小提琴音量

在 `midi/` 里放一个和 MIDI 同名的 `.vol` 文件，内容就一个数字：

- `0`＝这首**不合奏**（小提琴完全不进，钢琴照常）；
- `1`＝默认音量（不写 `.vol` 也是 1）；
- `0.2`–`1.5` 之间微调，例如 `0.72` 就是比默认轻 28%。

例：`midi/07-kusha.vol` 写 `0.72`，哭砂的小提琴就轻一些；`midi/04-my-soul-your-beats.vol`
写 `0.42`，Angel Beats 的小提琴旋律就不会盖过钢琴；`midi/08-contra-jungle.vol` 写 `0`，
魂斗罗第一关不合奏。后台「曲库管理」每行新增的「伴奏音量」输入框
改的就是这个文件（填 1 或留空会删掉 `.vol`）。

音量作用于**所有小提琴音**：多轨曲的小提琴旋律、单轨曲生成的和弦伴奏、手排的 `.violin.json` 都算；
钢琴不受影响。多轨旋律还会按同一时刻叠了几个音做 `1/vp` 衰减（见 1.3.8），叠置处不会突然变响。

### 手排小提琴声部（覆盖自动伴奏）

如果某一首想要人耳编配，不用改 JS：在 `midi/` 放一个 `<同名>.violin.json`，自动伴奏就会被整个替换掉：

```json
{"notes":[[开始秒, 时值秒, MIDI音高, 力度], ...]}
```

- 时间以「剪掉开头空白后」的曲子时间为准，和播放器进度一致；时值单位是秒；
- 只写小提琴声部，钢琴仍照原谱弹；`.vol` 音量倍率继续生效；
- 没有这个文件就继续用自动分析；
- 文件名例：`07-kusha.violin.json`、`06-nikki-die-meng-hua-wu-yu.violin.json`。

《哭砂》《蝶梦花雾雨》已经按段落手排了一版：

- **哭砂**：前奏留白；主歌用引导音（三音/五音）长音加低音垫底；副歌跟旋律做三/六度和声；
  间奏留 4 小节再进；第二段升高音区；结尾收在 C 和弦。
- **蝶梦花雾雨**：前奏留白；A 段两小节一个长音；B、D 段跟旋律做和声；C、E 段回长音；
  结尾收在 D 和弦。

- 每种音色第一次选用各要下 0.8–3 MB（鼓组约 0.8 MB、其余 2–3 MB，之后浏览器缓存），
  切换模式会从当前进度接着放，不打断。

## 架子鼓+钢琴怎么工作

音色选「架子鼓+钢琴」时，MIDI 打击乐轨（channel 10）的音符按 **GM 打击乐键位**用真鼓组采样发声
（36 底鼓、38 军鼓、42/46 闭镲／开镲、49 吊镲、51 叮镲、嗵鼓等），其余声部照常由钢琴弹：

- 鼓件自动分档音量：底鼓／军鼓当家（1.0／0.9），踩镲吊镲收敛（约 0.5），避免糊成一团；
  鼓声也过混响，跟钢琴粘在一起。
- 曲子没鼓轨＝听感就是纯钢琴，不会硬造节奏。
- 每首歌可以单独调鼓音量：`midi/` 里放同名 `.dvol` 文件，内容一个数字——
  `0`＝这首**不打真鼓**（等于回到从前的「鼓轨忽略」），`1`＝默认，
  `0.2`–`1.5` 之间微调。例：`midi/08-contra-jungle.dvol` 写 `0`，因为这首 1.4.2 已经手排过
  钢琴化鼓点轨，避免两套鼓叠在一起；想听原版真鼓就把这个文件删掉（建议同时去掉手排鼓点轨）。
- 后台「曲库管理」暂无 `.dvol` 输入框，用文件方式管理（和 `.vol` 同目录同名）。

## 实现要点

- **解析**：一次把整首 MIDI 读成音符数组（秒为单位），把开头的空白剪掉；CC64 踏板按下期间，
  音符自动延长到踏板松开，避免听起来一顿一顿。
- **发声**：每个音符建一个 `AudioBufferSourceNode`（用最近音高的采样，必要时按半音移调），
  增益按力度做包络；主输出接一个很轻的卷积混响（程序生成的短脉冲响应）。
- **调度**：每 200 ms 排一次未来 1.5 秒内的音符，后台标签页被节流也不会断音。
- **切曲**：新曲一个声部从 0 淡入、旧曲淡出，二者交叠 `fade` 秒；暂停 / 拖动进度时会停掉所有已排的音。
- **省内存**：只解码当前曲目用到的琴键（一般 20–50 个），不是一次把 88 键全解成 PCM。
- **续播**：曲目、秒数、音量、音色、循环、面板状态都存 `localStorage`；页面卸载前记录当前秒数。
  浏览器自动播放策略挡下时用「继续播放」胶囊兜底（点链接不会触发，避免放半秒又断）。
- **缓存**：静态资源 URL 带 `?v=<文件修改时间>`，换音色 / 改 JS 后浏览器自动拿新的。

## 已知限制

- 浏览器不允许网页凭空出声：第一次一定要有一次点击；换页续播也可能需要点一下「继续播放」。
  想要真正一点都不断，只能做无刷新浏览（PJAX），那会接管站内跳转，本插件没做。
- 手机第一次播放要下载约 2.2 MB 音色（之后走浏览器缓存），流量敏感可后台关掉手机版。
  切到别的音色会再多下一次那种音色（同样 2–3 MB），只下一次。
- 九种音色里七种是「单音色」：多乐器 MIDI 的所有声部都用当前选的音色弹（「小提琴+钢琴」按声部
  分小提琴与钢琴，「架子鼓+钢琴」按声部分鼓与钢琴）；除「架子鼓+钢琴」外的模式鼓轨都忽略。
- 不读数据库，曲目信息就是文件名 + 同名 `.txt`。

## 卸载

后台停用或卸载插件即可：没有数据表、没有改模板；`source/plugin/edpiano/` 整个目录可直接删除，
会员浏览器里的 `edpiano.v1` localStorage 会自然失效。
